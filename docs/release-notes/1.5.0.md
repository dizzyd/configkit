1.5.0 is released! Settings screens for mods that ship none, if you ask for them.

For players

* Mods that ship no settings screen can get one. Set "AutoConfigs": true in ModConfig/configkit.json and ConfigKit builds a screen for every mod that reads its config with LoadModConfig. It is off by default, and takes effect the next time a world loads. With it off, the log says how many installed mods it could cover.
* An auto-built screen edits the mod's own JSON file in place and keeps the comments in it. A mod that already describes its settings to ConfigKit keeps its own screen.
* Mod settings opened from the pause menu came up behind it, with the menu covering the middle of the window. Settings now open in front, and Escape closes just the settings, leaving the world paused.
* With configlib installed, ConfigKit stands down. Joining a server that runs ConfigKit then died with a NullReferenceException while loading. You are now sent back to the disconnect screen with the reason, rather than joining with settings that disagree with the server's.

For mod authors

* Nothing to change. A mod with its own ConfigKit or configlib settings is never given an auto-built screen, and neither is a mod named under UnmanagedDomains.
