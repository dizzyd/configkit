1.5.3 is released! ConfigKit works on the 1.23 pre-release, from the same download as 1.22.

For players

* On 1.23.0-pre.1 the game ignored ConfigKit. The log said that TryResolveAsset in ConfigKit.SettingsOrigin does not have an implementation, and there was no settings screen. ConfigKit now loads there, and settings open, save and sync to the server as on 1.22.
* One download covers both versions. It was tested on 1.22.7 and 1.23.0-pre.1; later 1.23 pre-releases may change more.

For mod authors

* Nothing to change. ConfigKit's API is the same, so a mod built against an earlier 1.5 release needs no rebuild for this one.

Thanks to Bannta (https://mods.vintagestory.at/show/user/1DB7D95AA1955D0519F1) for reporting it, and for finding what stopped ConfigKit loading.
